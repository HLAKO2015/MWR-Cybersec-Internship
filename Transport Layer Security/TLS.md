# 12. Transport Layer Security
- A protocol that provides a secure communication over a network
- It insures that the data exchanged between client and server can't be intercepted, modified or impersonated by attackers

### 12.1 What TLS provides
- Confidentiality : Encrypts data so that only the intended sender and receiver can read it
- Integrity : Detects whether data has been altered during transmission
- Authentication : Verifies that the client is communicating with the legitimate server using digital certificates

### Why TLS is important
- Without it, attackers could :
  (i) Read sensitive information such as passwords or credit card numbers
  (ii) Modify data while it is in transit
  (iii) Impersonate legitimate websites
